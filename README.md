# LOS NÚMEROS DE LUCAS · FuturMovil

App para aprender matemáticas (4 a 8 años, de Infantil a 3º de Primaria) con Lucas, el robot de FuturMovil.
Misma base que *Leo con Lucas*: planetas, personajes, recreo, taller, diplomas, pago único y modo admin con llave NFC.

- **Frontend:** GitHub Pages (`index.html`, `style.css`, `app.js`, `engine.js`, `data.js`, `extras.js`, `recreo2.js`, PWA con `manifest.json` y `sw.js`).
- **Backend:** Apps Script «los numeros de lucas» (`apps-script/Code.gs`) + Google Sheet «los numeros de lucas».
- **25 planetas:** números 1-5, hasta 10, comparar, formas y series, sumas/restas hasta 5, 10 y 20, decenas, hasta 100,
  pares e impares, dos cifras, dinero, la hora, llevando, tablas (2-5-10, 3-4, 6-9), división (repartos y divisiones exactas) y Galaxia Genio.
- **Cada edad empieza en su planeta:** 4 años → 1, 5 → 3, 6 → 5, 7 → 9, 8+ → 21 (tablas) (los anteriores quedan abiertos).
- **Reto del día:** historia de Lucas según la fecha (Navidad, Reyes, Fallas, Pascua, verano, Halloween…) con 5 retos de cálculo.
- **Sin repeticiones:** memoria por niño (lo visto hace poco sale menos, lo fallado se repite más) y el reto sube al repetir planeta.
